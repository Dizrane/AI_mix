# Changelog

Русский журнал изменений. Release-workflow берёт отсюда раздел публикуемой версии и вставляет его в заметки релиза как «Что нового»; если раздела для версии нет, в заметки попадает автоматический список коммитов. Перед выпуском новой версии добавьте сюда её раздел.

## v0.2.0 — 2026-08-13

### Установка стала проще

- Приложение теперь само лечит App Translocation. Если macOS запустил его из карантинной read-only копии и хранилище данных недоступно, прямо в этом сообщении появляется кнопка **Fix and Relaunch**: она снимает карантин только с папки программы и перезапускает её из настоящего места. Папку можно держать где угодно — включая рабочий стол.

### Удобство

- Статус подключения обновляется сам: запустили Logic Pro или выдали разрешение Accessibility — экран Connection оживает без кнопки Refresh.
- Диалог подтверждения экспорта теперь честно описывает автоматический процесс (раньше он описывал старый ручной сценарий с ⌘⇧G и вставкой пути).
- Буфер обмена больше не затирается: автоматика экспорта сохраняет и восстанавливает то, что вы скопировали.
- После сканирования и запуска экспорта приложение возвращает себя на передний план, а не оставляет вас в Logic.
- Определение экспортированных WAV больше не обрывается через 2 минуты: ожидание продолжается, пока файлы появляются (до 10 минут), и завершается после минуты без изменений — большие проекты успевают.
- Если меню Logic не на английском, ошибка теперь прямо объясняет, что Logic Pro нужно переключить на английский интерфейс, и подсказывает как.
- В сайдбаре видна версия приложения.

## v0.1.2 — 2026-08-13

- Перед каждым анализом приложение само открывает Mixer в Logic (View ▸ Show Mixer), чтобы скан видел все channel strips.
- Иконка приложения и её включение в релизные сборки.

## v0.1.1 — 2026-08-13

- Дистрибуция «закрытой оболочкой»: одна папка владеет приложением, его данными и удалением; полное самоудаление через Settings.

## v0.1.0 — 2026-08-13

- Первый выпуск: read-only анализ проекта Logic Pro через Accessibility, нормализация фактов, экспорт аудио через собственный диалог Logic, генерация AI-пакета для внешней LLM и валидация MixPlan.
